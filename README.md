# MLOps-LLMOps

Learning exercises and a cloud MLOps portfolio project share this repository.

| Location | Purpose |
| --- | --- |
| `first_practice/` | Iris / MLflow learning exercises |
| `src/mlops_llmops/citibike/` | Citi Bike availability project |
| `docs/citibike/` | Project plan and first-step guide |
| `tests/` | Automated checks using synthetic data |
| `data/` | Collected data, excluded from Git |

The Citi Bike project predicts whether a station will have zero rentable bikes
30 minutes ahead. Collection, dataset versioning, training, deployment, and
monitoring will be built incrementally in AWS Mumbai (`ap-south-1`).

Start with the [project plan and collection guide](docs/citibike/README.md).
